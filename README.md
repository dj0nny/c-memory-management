# C — Pointers & memory management

A collection of C exercises focused on understanding pointers and memory management.

---

## Concepts

The main concepts covered are:

1. Pointer fundamentals
2. Arrays, pointers & memory layout
3. Dynamic memory
4. Memory bugs
5. Dynamic data structures
6. Function pointers
7. Struct, pointers & ownership
8. Advanced memory management
9. Projects

---

## Requirements

* C11 or later
* CMake 3.20+
* GCC / MinGW

---

## Run the programs

```bash
cd /programs-folder
gcc programs-name.c -o programs-name
./programs-name
```
